# ConnectCCM Introduction

## Welcome to ConnectCCM

Welcome to ConnectCCM – your advanced environmental monitoring system designed to ensure optimal conditions for both personnel and sensitive equipment onboard your vessel. This system will serve as an essential tool for maintaining comfort, safety, and operational efficiency throughout your vessel.

## What is ConnectCCM?

ConnectCCM is a comprehensive environmental monitoring solution that allows for connecting desired Bluetooth or Modbus sensors to the system, allowing for the user to track sensor data throughout the vessel. The system provides real-time data, historical trends, and automated alerts to help you maintain optimal environmental conditions. The system consists of:

- **BLE Sensors** – Sensors that collects data wireless data via BLE
- **Modbus Sensors** - Sensors connected to the mesh node via Modbus
- **Mesh Network** – Wireless communication system that transmits data to the central system
- **Connect OWC Web GUI** – Intuitive graphical interface accessible through your browser
- **Alert System** – Automated notifications when environmental conditions exceed set thresholds
- **Data Visualization Tools** – Dashboards and reports for analyzing environmental trends

## Getting Started

To begin using ConnectCCM:

1. **Ensure proper installation** of sensors in key locations as detailed in this manual
2. **Complete the configuration process** in the ConnectCCM UI
3. **Set up appropriate alarm thresholds** for different areas and functions
4. **Create customized dashboards** that meet your specific monitoring needs
5. **Train relevant personnel** on system operation and response procedures

## System Requirements

ConnectCCM operates as a "plug-in" solution on your vessel's existing Onboard Wireless Connectivity (OWC) system. The system requires:

- **Properly placed sensors** in areas requiring environmental monitoring
- **Connection to the onboard server** with UPS backup power
- **Internet connection** for two-way communication with ScanReach cloud services
- **Access to integrated resources** on the local area network if configured
- **Internal Wi-Fi access** preferably on UPS for tablet connectivity
