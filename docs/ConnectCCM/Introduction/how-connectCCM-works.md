## How ConnectCCM Works

The system operates through a network of wireless sensors and communication devices:

1. **Sensors BLE & Modbus** placed throughout the vessel measure the desired data
2. **The Mesh Network** wirelessly transmits this data to the central system
3. **The Connect OWC Web GUI** processes and presents this data in an intuitive format
4. **The Alert System** notifies designated personnel when conditions exceed set parameters
5. **Data Visualization Tools** allow for analysis of trends and historical data
