# ConnectFuel Introduction

## Welcome to ConnectFuel

Welcome to ConnectFuel – your advanced fuel consumption monitoring and management system designed specifically for maritime operations. This system will serve as an essential tool for optimizing vessel performance, ensuring regulatory compliance, and making informed decisions about fuel management.

## What is ConnectFuel?

ConnectFuel is a sophisticated system that measures, visualizes, and analyzes engine fuel consumption in real-time. It provides you with accurate data to optimize vessel operations, reduce fuel costs, and minimize environmental impact. The system consists of:

- **Flowmeters** – Precision instruments that measure actual fuel consumption
- **Flow Computers** – Devices that record and transmit fuel data to the system
- **Modbus Mesh Nodes** – Wireless communication devices that transmit data from the flow computer to the central system
- **Gateway** – Central processing unit that collects and manages all fuel data
- **ConnectFuel UI** – Intuitive graphical interface accessible on the bridge and other key locations

## Getting Started

To begin using ConnectFuel:

1. **Ensure proper installation** of all hardware components as detailed in this manual
2. **Complete the configuration process** in the ConnectFuel UI
3. **Familiarize yourself with the dashboard** and data visualization tools
4. **Set up custom reports** that align with your operational and reporting needs
5. **Train key bridge team members** on system operation and interpretation

## System Requirements

ConnectFuel operates as a "plug-in" solution on your vessel's existing Onboard Wireless Connectivity (OWC) network. The system requires:

- **Properly installed flowmeters** on relevant fuel lines
- **Connection to the onboard server** with UPS backup power
- **Internet connection** for two-way communication with ScanReach cloud services
- **Access to integrated resources** on the local area network if configured
- **Internal Wi-Fi access** preferably on UPS for tablet connectivity
