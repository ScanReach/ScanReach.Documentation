# How ConnectFuel Works

The system operates through a network of sensors and communication devices:

1. **Flowmeters** installed on fuel lines measure actual fuel consumption
2. **Flow computers** collect and process this measurement data
3. **Modbus mesh nodes** wirelessly transmit data to the central system
4. **The gateway** processes and stores the information
5. **The ConnectFleet UI** presents this data in an intuitive, visual format for analysis and decision-making
