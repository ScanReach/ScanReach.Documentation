# Installation Overview

## What You'll Be Installing

The OWC system consists of several key components that you'll be installing:

- **Gateway Computer** – The central communication hub for the OWC system
- **Root Node** – The main anchor point for the mesh network
- **Mesh Nodes** – Wireless communication devices placed throughout the vessel
- **Deck Boxes** – Weatherproof enclosures for nodes in exposed areas
- **Power Supplies** – Components to power the system with appropriate backups

## The Installation Process

This manual will guide you through a step-by-step installation process:

1. **Pre-Installation** – Understanding components and requirements
2. **Installation Step 1** – Setting up the gateway and root node
3. **Installation Step 2** – Installing and configuring mesh nodes
4. **Installation Step 3** – Verifying the installation and system functionality

## Who This Manual Is For

This manual is designed for installers who may be:

- **Ship crew members** with technical responsibilities
- **IT professionals** with networking experience
- **Marine electronics technicians**
- **Shipyard personnel** involved in vessel outfitting

No specialized wireless networking expertise is required, but basic technical skills and familiarity with vessel layouts will be helpful.

## What You'll Need

Before beginning installation, ensure you have:

- **All OWC components** as specified in your vessel's configuration
- **Basic tools** for mounting and securing components
- **Access to vessel power systems** as required
- **Network access** for the gateway computer
- **Vessel documentation** including general arrangement plans

## Safety Considerations

Safety is paramount during installation:

- Follow all vessel safety procedures
- Ensure proper isolation of electrical systems before making connections
- Use appropriate personal protective equipment
- Coordinate with vessel officers before beginning work
- Be aware of your surroundings in potentially hazardous areas

## Getting Started

To begin the OWC installation:

1. **Review all components** against the packing list
2. **Familiarize yourself** with the vessel layout and installation locations
3. **Read through this entire manual** before starting work
4. **Gather all necessary tools** and equipment
5. **Coordinate with vessel management** about installation schedules and access requirements
