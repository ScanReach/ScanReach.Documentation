# Data & Monitoring

This section covers questions about data visualization, system monitoring, alarm configuration, and sensor management for ScanReach products.

## Data Visualization

<br>

<details>
<summary>How do I visualize fuel consumption data?</summary>
To visualize fuel consumption data:
<ol>
    <li>Open a browser and visit: https://your-vessel-domain-name.edge.scanreach.com/connect/data<ul><li><strong>your-vessel-name</strong> is to be replaced with your vessels name</li></ul></li>
    <li>Log in with your credentials</li>
    <li>You will land on the Data Visualization page</li>
    <li>Available data is listed on the right side as Data Sources</li>
    <li>Click on a data source of interest to load and plot measurements</li>
    <li>Hover over any point in the chart to see more details</li>
    <li>You can select multiple data sources to compare trends and values</li>
</ol>
</details>

<details>
<summary>How do I customize the data visualization time period?</summary>
To customize the time period:
<ol>
    <li>Click on the time period control panel</li>
    <li>Edit both the start (FROM) and end (TO) of your time period</li>
    <li>Click "Update" to confirm and update the chart</li>
    <li>Alternatively, select one of the shortcuts for commonly used time windows</li>
    <li>To stream live data, toggle the "Live data" control in the top-right corner</li>
</ol>
</details>

<details>
<summary>How do I create a dashboard?</summary>
To create a dashboard:
<ol>
    <li>Click the new dashboard icon in the navigation menu or open https://your-vessel-name.edge.scanreach.com/connect/dashboard<ul><li><strong>your-vessel-name</strong> is to be replaced with your vessels name</li></ul></li>
    <li>If no dashboard is configured, click "Add a New Dashboard"<ul><li>If you want to create a new dashboard click the "plus" icon</li></ul></li>
    <li>Enter the name of the Dashboard and press "Save"</li>
    <li>A new Dashboard is created and a widget is added with the name of the Dashboard</li>
    <li>Click the icon that looks like 3 squares and a plus icon to add new widgets</li>
    <li>Widgets can be moved to desired locations or resized as needed</li>
</ol>
</details>

<details>
<summary>What types of widgets are available for dashboards?</summary>
There are 5 different widget types available:
<ul>
    <li>Current measurement - Shows currently measured values and their unit</li>
    <li>Vessel Location map - Displays your vessel's current location on a world map, optionally with track over time</li>
    <li>Measurement trend over time - Shows the trend of measured values over time</li>
    <li>Free text - Allows you to add notes or text to your dashboard</li>
    <li>Fuel type log - Enables you to creates a log of changes in Fuel type, Density, Sulfur or Viscosity and when changes occurred. The fuel usage is logged with the mesh node via the flow computer</li>
</ul>
</details>

<details>
<summary>How do I export sensor data?</summary>
To export data:
<ol>
    <li>Click on the "export data" button in the top-left corner of the data visualization page</li>
    <li>If you haven't saved any template, click "next"</li>
    <li>Select the data sources providing the measurements you want to export</li>
    <li>Select the time period of interest</li>
    <li>Optionally specify intervals and value types</li>
    <li>Review the export parameters</li>
    <li>Click "export as .csv" or "export as .xlsx" to download your report</li>
    <li>Optionally save the configuration as a template for future use</li>
</ol>
</details>
