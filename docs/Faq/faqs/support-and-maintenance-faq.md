# Support & Maintenance

This section covers questions about troubleshooting, maintenance procedures, and getting technical support for ScanReach products.

## Troubleshooting

<br>

<details>
<summary>What maintenance is required for the flowmeter system?</summary>
Maintenance tips for the flowmeter system:
<ul>
    <li>The silicone grease should be reapplied to the sensors every 6 months</li>
    <li>Refer to the user manuals for other maintenance needs</li>
</ul>
User manuals for the ultrasonic flow transmitter and sensors can be found under "Manual" on Fuji's product pages:
<ul>
    <li>FSV-2: https://www.fujielectric.com/products/instruments/products/flow_ultra/FSV.html</li>
    <li>FSV-2 Advanced: https://www.fujielectric.com/products/instruments/products/flow_ultra/FSV2.html</li>
</ul>
</details>

<ul>
