# Gangway Page

**Purpose:** Monitor and manage personnel transfers on and off the vessel through gangways, ensuring accurate tracking of who is aboard.

## What You Can Do:

### Gangway Monitoring

- **View gangway status:** See which gangways are active and monitoring transfers
- **Activate/deactivate gangways:** Turn monitoring on/off for specific gangways
- **Real-time detection:** Monitor automatic detection of personnel transfers

### Transfer Management

- **Review detected transfers:** See all automatically detected boarding/disembarking actions
- **Approve detections:** Confirm that detected transfers are accurate
- **Reject false detections:** Remove incorrect automatic detections
- **Manual transfer recording:** Manually log transfers when automatic detection fails

### Gangway Detections Table

- **View pending detections:** See all transfers waiting for approval
- **Bulk approval:** Select and approve multiple transfers at once
- **Individual review:** Examine each detection with person details, time, and location
- **Violation tracking:** See any policy violations (like unauthorized transfers)

### Personnel Actions History

- **View transfer history:** See complete log of all approved transfers
- **Search history:** Find specific transfers by person name or action type
- **Export logs:** Generate reports of gangway activities

### Multi-Gangway Operations

- **Multiple gangway support:** Monitor several gangways simultaneously
- **Gangway identification:** See which specific gangway detected each transfer
- **Location tracking:** Know exactly where transfers occurred

### Mobile Interface Options

- **Switch between views:** Toggle between pending detections and approved actions
- **Optimized for tablets:** Interface adapts for easier use on mobile devices
