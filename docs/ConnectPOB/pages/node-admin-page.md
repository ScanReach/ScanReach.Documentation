# Node Admin Page

**Purpose:** Configure and manage the network of tracking nodes throughout the vessel that enable personnel positioning and safety monitoring.

## What You Can Do:

### Node Configuration

- **View all nodes:** See complete inventory of tracking nodes throughout the vessel
- **Place nodes on map:** Position nodes accurately on the vessel layout
- **Configure node settings:** Adjust technical parameters for optimal performance
- **Node debugging:** Access diagnostic information for troubleshooting

### Network Management

- **Monitor node status:** See which nodes are online, offline, or having issues
- **View node relationships:** Understand how nodes connect and communicate
- **Network topology:** Visualize the mesh network structure
- **Signal strength monitoring:** Check communication quality between nodes

### Node Grouping

- **Create node groups:** Organize related nodes into logical groups
- **Group management:** Add/remove nodes from groups
- **Bulk operations:** Configure multiple nodes simultaneously
- **Group visualization:** View groups on the map for better organization

### Map Integration

- **Interactive map view:** See all nodes positioned on the vessel layout
- **Node placement:** Drag and drop nodes to correct positions
- **Zoom and navigation:** Navigate the vessel map to locate specific nodes
- **Visual indicators:** See node status through color coding and icons

### Search and Filtering

- **Search nodes:** Find specific nodes by name or MAC address
- **Filter by status:** Show only connected, disconnected, or problematic nodes
- **Filter by type:** View different types of nodes (regular, muster stations, etc.)
- **Node relationships toggle:** Show/hide network connection lines

### Technical Management

- **Node placement mode:** Special mode for physically positioning new nodes
- **Hardware diagnostics:** Access technical details about node performance
- **Network troubleshooting:** Identify and resolve connectivity issues
- **Firmware management:** Monitor and update node software
