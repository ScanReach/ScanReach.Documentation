# User Admin Page

**Purpose:** Manage system users who have access to the ConnectPOB application, including their permissions, roles, and account settings.

## What You Can Do:

### User Account Management

- **Add new users:** Create accounts for people who need system access
- **View all users:** See complete list of system users
- **Edit user details:** Update user information, contact details, and settings
- **Delete users:** Remove accounts that are no longer needed

### User Information

- **Personal details:** Manage names, email addresses, and contact information
- **Account credentials:** Handle usernames and password requirements
- **User roles:** Assign different permission levels and access rights
- **Account status:** Enable/disable user accounts as needed

### Access Control

- **Role assignment:** Set what each user can access in the system
- **Permission management:** Control specific features users can use
- **Account activation:** Enable new user accounts after creation
- **Account suspension:** Temporarily disable accounts when needed

### Search and Filtering

- **Search users:** Find specific users by name, email, or username
- **Filter by role:** View users with specific permission levels
- **Filter by status:** See active, inactive, or suspended accounts
- **Sort users:** Order by name, creation date, or last login

### Bulk Operations

- **Select multiple users:** Use checkboxes to work with groups of users
- **Bulk role changes:** Assign roles to multiple users simultaneously
- **Bulk status updates:** Enable/disable multiple accounts at once

### User Details

- **Profile management:** View and edit comprehensive user profiles
- **Login history:** Track when users access the system
- **Activity monitoring:** See what actions users have performed
- **Contact information:** Manage email, phone, and other contact details

### Security Features

- **Password policies:** Enforce strong password requirements
- **Account lockout:** Handle security measures for failed login attempts
- **Session management:** Monitor and control user sessions
