# How ConnectPOB Works

The system operates through a wireless mesh network that covers your entire vessel:

1. **Your wearable device** is assigned to you when you join the vessel
2. **Mesh nodes** throughout the vessel detect and track your wearable
3. **The gateway** processes this information and makes it available through the system interface
4. **Authorized personnel** can view real-time information about personnel location and status
5. **In an emergency**, you can activate your wearable's distress function to alert others
